# WPS office walkthrough concept

An interactive Three.js concept for Workplace Solutions. Scroll through five office settings or jump between chapters. Includes still-view mode.

This is an illustrative design prototype, not the production WPS website. Architecture, furniture finishes and scene scale are conceptual. Six Cesto lounge chairs use the mesh supplied in the project attachment.

`visual-direction.png` shows the intended visual finish; the walkthrough combines simplified procedural geometry with the optimized Cesto mesh (12,000 triangles shared across six chairs).
