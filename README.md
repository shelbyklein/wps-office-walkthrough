# WPS office walkthrough concept

An interactive Three.js concept for Workplace Solutions. Scroll through five office settings or jump between chapters. Includes still-view mode.

This is an illustrative design prototype, not the production WPS website. Furniture and architecture are conceptual.

`visual-direction.png` shows the intended visual finish; the walkthrough uses simplified procedural geometry.
